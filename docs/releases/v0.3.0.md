# v0.3.0 — OCR, document permissions and model evaluation tooling

This research preview adds page OCR, document ACLs, configurable parsing budgets and lazy
PostgreSQL navigation. A collection larger than 10,000 nodes no longer forces lexical-only
retrieval. Broad sibling sets still use a bounded lexical shortlist before navigation.

Default ceilings are now 25 MB, 2,000 PDF pages and 50,000 nodes per document; resource
deadlines and memory limits remain active. Native PDF chapter inference is not included.
Current ACLs protect current/historical content and model candidates. Legacy documents
preserve namespace-wide access until an administrator explicitly restricts them.

Ollama integration includes local secret configuration, bounded requests, response validation
and usage reporting. The routing dataset has 392 training, 84 validation and 64 synthetic
test examples, while 44 public benchmark questions remain held out. Optional LoRA tooling
and base/adapted comparison checks support a future author-trained Hugging Face release.

No cloud LLM benchmark, trained checkpoint, measured fine-tuning improvement or STAIR
reproduction is claimed. Training preparation is verified; full GPU training remains unexecuted.
Read [upgrade instructions](../upgrade-v03.md), [evaluation workflow](../llm-evaluation.md)
and [security boundaries](../../SECURITY.md) before adopting the preview.

57 tests passed on Linux/Python 3.12 with PostgreSQL 17. Validation covers real image-PDF OCR,
a 201-page PDF, a document with 11,002 nodes,
database-level document ACLs, historical access, key rotation, lazy retrieval, malformed
provider responses and reproducible training exports. Live Compose migration to schema 4,
API smoke checks and restoration into a separate temporary database passed. Ruff and the
installed Python dependency audit passed; operating-system packages and the optional GPU
training environment are outside that audit. An upstream Starlette/httpx deprecation warning
remains visible in tests.

The [rerun benchmark](../evaluation.md) retains test Recall@5 of 0.5833 for local navigation,
0.4444 for lexical and 0.9167 for MiniLM dense retrieval. The dense baseline remains stronger
on this small draft corpus. Neither the new limits nor these timings establish production
scale or retrieval superiority.
